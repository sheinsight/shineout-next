手动测试

新标签页打开单个版本，自己点击，页面顶部会记录浏览器 Event Timing（INP 的来源）与点击→绘制耗时。也可以配合 DevTools Performance 面板录制对比。

说明

  • 主线程：点击事件及其微任务的 JS 耗时 + 下一帧样式/布局/绘制耗时，排除了等待 vsync 的空闲时间，适合横向对比；点击→绘制：从派发点击到下一帧绘制完成的总耗时，近似 INP，受帧对齐影响会有 0~16ms 的随机波动。
  • render 次数：「商品信息」列 render 的调用次数，约等于本次交互重渲染的行数。
  • 每次测量前都会校验交互确实生效（勾选数、单元格内容等），失败次数会显示在表格中，有失败的数据不可信。
  • Table props 两边一致：keygen、bordered、width=1700、fixed="x"（2.x 固定列 + 渲染全部行的写法，3.x 中同样是非虚拟列表）、sticky={ top: 0, css: true }、勾选。
  • 2.x 样式是预编译 CSS，3.x 是运行时 CSS-in-JS，这是两个版本真实的交付形态，属于对比的一部分。
  • 测试期间请保持本页在前台且不要操作，后台标签页的 rAF 会被节流导致数据失真（会被标记）。
