# Title

InputNumber 数字输入框
InputNumber

# Describe

用于输入数字的输入框，API 与 Input.Number 一致，区别是 allowNull 默认为 true：清空内容后值为 null，失焦时不会回填 0 或 min。
An input for numbers. The API is the same as Input.Number, except that allowNull defaults to true: clearing the content gives null, and blur does not refill 0 or min.
